# USMLE Visual Mnemonic Studio

Interactive visual mnemonic learning tool for USMLE Step 1, built in the style of Picmonic/Sketchy — powered by [Servier Medical Art](https://smart.servier.com/) (Creative Commons CC BY 4.0).

## Files

| File | Description |
|------|-------------|
| `index.html` | Full quiz + flashcard app (36 questions, 7 categories) |
| `mnemonics-cheatsheet.html` | One-page reference sheet with search & category filter |

## Features

- **Quiz mode** — 4-option MCQs with instant feedback and explanations
- **Flashcard mode** — Flip-card review of all 36 mnemonics
- **Visual scenes** — Servier Medical Art illustrations embedded as base64 (no CDN dependency)
- **7 categories** — Neuro, Hypertensive Neuro, Pathology, Genetics, Stats/Pharm, Immunology, Physiology
- **Cheat sheet** — Live search + category filter across all 36 mnemonic scenes

## Usage

Open either HTML file directly in a browser — no server or build step required.
